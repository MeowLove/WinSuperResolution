# WinSuperResolution

[English](../README.md) | [简体中文](README.zh-CN.md) | [Русский](README.ru-RU.md)

Повышенное виртуальное разрешение и масштабирование в стиле HiDPI для Windows.

WinSuperResolution помогает настроить повышенное виртуальное разрешение рабочего стола Windows и сочетать его с системным масштабированием, чтобы получить более чёткое и просторное рабочее пространство, близкое по ощущению к HiDPI.

## Сценарии использования

WinSuperResolution предназначен для следующих сценариев:

- Использование повышенного виртуального разрешения рабочего стола на дисплеях класса 1080p для отображения большего количества содержимого.
- Использование виртуального рабочего пространства, близкого к 4K, на дисплеях класса 1440p.
- Сочетание виртуального разрешения с масштабированием Windows для более чёткого и просторного интерфейса в стиле HiDPI.
- Улучшение соответствия размеров интерфейса и макета, когда рекомендуемый процент масштабирования недоступен или даёт неудовлетворительный результат.
- Баланс между читаемостью текста и доступным рабочим пространством вместо слишком крупного или тесного интерфейса.

Типичные примеры:

- Дисплей 1080p → виртуальное разрешение рабочего стола около 1.5K или выше.
- Дисплей 1440p → виртуальное рабочее пространство около 4K или выше.
- Дисплей 4K → увеличенное виртуальное рабочее пространство с подходящим масштабированием Windows.

Обычный порядок работы: настроить возможность виртуального разрешения, при необходимости перезапустить Windows или повторно инициализировать графический стек, выбрать текущий режим рабочего стола Windows и затем настроить масштабирование. Для приложений с поддержкой DPI Windows это помогает улучшить макет, читаемость текста и баланс рабочего пространства; физическое количество пикселей панели не изменяется, и одинаковый результат во всех приложениях не гарантируется.

## Возможности

- Сканирует зарегистрированные конфигурации дисплеев, включая исторические записи.
- Планирует повышенное виртуальное разрешение на основе активного сигнала или зарегистрированного размера поверхности.
- Применяет изменения для каждого дисплея отдельно, а также поддерживает проверенную пакетную операцию.
- Позволяет тестировать и применять текущее разрешение рабочего стола, включая поддерживаемые режимы виртуального рабочего стола.
- Предоставляет экспериментальное масштабирование для отдельных дисплеев, резервное копирование и восстановление.
- Поддерживает английский, упрощённый китайский и русский языки.

Инструмент изменяет конфигурацию дисплея Windows. Это не ИИ-апскейлер изображений и он не предоставляет NVIDIA DLSS, AMD FSR, Intel XeSS или аналогичные функции рендеринга GPU.

## Требования

- Windows 11 24H2 или новее
- 64-разрядная система
- .NET Framework 4.8.1
- Права администратора

## Использование

1. Скачайте или соберите `WinSuperResolution.exe`.
2. Запустите программу и подтвердите запрос прав администратора.
3. Выберите конфигурацию дисплея из списка.
4. Выберите коэффициент увеличения и сформируйте предварительный план.
5. Проверьте цели операции и подтвердите её.
6. Для разрешения рабочего стола выберите режим и используйте **Test & apply desktop mode**. Сохраните новый режим во время обратного отсчёта подтверждения; иначе он будет восстановлен автоматически.
7. Для экспериментального масштабирования выберите процент и примените его. При необходимости выйдите из системы или перезапустите Windows.

Кнопка **Display Settings** остаётся доступной для ручной настройки Windows.

## Диагностика и GitHub Issues

Если активный дисплей отображается как `Candidate` или `Configuration conflict`, либо WinSuperResolution показывает больше активных дисплеев, чем физически подключено, не применяйте режим рабочего стола, масштабирование или виртуальные возможности. Строки списка представляют конфигурации реестра, а не число физических дисплеев; только уникальное стабильное совпадение идентификатора становится `Active + Exact`. Исторические записи, не заменённые точным совпадением, могут оставаться доступными для отдельного плана виртуальных возможностей.

Чтобы сообщить о проблеме:

1. Воспроизведите проблему и запишите ожидаемый и фактический результат.
2. В WinSuperResolution нажмите **Export Diagnostic Package**.
3. Найдите созданный ZIP рядом с исполняемым файлом в каталоге `diagnostics/`: `WinSuperResolution-diagnostic-*.zip`.
4. Откройте [GitHub Issue](https://github.com/MeowLove/WinSuperResolution/issues), опишите шаги воспроизведения и прикрепите ZIP, перетащив его в форму Issue.

Укажите версию WinSuperResolution, версию и номер сборки Windows, количество физических дисплеев, тип подключения и сохраняется ли проблема после перезапуска Windows. Если диагностический пакет доступен, не ограничивайтесь одними скриншотами: пакет содержит структурированные данные для анализа связи дисплеев и состояния реестра.

Диагностический пакет может содержать журналы приложения, журналы операций, экспорт реестра, существующие резервные копии реестра, снимки состояния дисплея, настройки приложения, идентификаторы мониторов и локальные пути. Перед загрузкой проверьте ZIP и удалите или замаскируйте сведения, которыми вы не хотите делиться. Пакет создаётся только локально и автоматически не загружается приложением.

Если проблема связи дисплеев сохраняется после экспорта диагностического пакета, используйте **Очистить кэш дисплея (финальное исправление)** только в крайнем случае. После подтверждения приложение сначала сохраняет резервные копии и журнал, удаляет кэш Windows `GraphicsDrivers\\Configuration`, `Connectivity` и `ScaleFactors` только после успешного резервного копирования, а затем немедленно перезапускает Windows для его восстановления. Сначала сохраните работу; операция сбрасывает конфигурацию всех дисплеев. При ошибке или частичном сбое автоматический перезапуск не выполняется.

## Портативные данные

Приложение хранит настройки и данные восстановления рядом с исполняемым файлом:

- `WinSuperResolution.settings.json`
- `backup_reg/`
- `backup_journal/`
- `display_state/`
- `logs/`
- `diagnostics/`

Перемещайте каталог программы целиком, чтобы сохранить переносимую конфигурацию.

## Сборка

Откройте `WinSuperResolution.sln` в Visual Studio и соберите конфигурацию `Release|x64`. Проект использует .NET Framework, устанавливаемый вместе со средствами разработки Windows, и не требует сторонних UI-фреймворков или сред выполнения.
